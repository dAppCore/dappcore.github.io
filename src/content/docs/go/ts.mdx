CoreTS — the TypeScript branch of the Core framework. The Go side (`dappco.re/go/ts`) is a
CoreGo service that orchestrates a sandboxed **Deno** runtime (gRPC + subprocess, a
permission model) to run TS modules securely. Shared APIs across the Go and TS branches.

## Install

```sh
go get dappco.re/go/ts@latest
```

## Import

```go
import "dappco.re/go/ts"
```

## Status

Page in flight — the module is at `go/v0.2.1` (early). Source of truth is the RFC and the
inline docstrings in the repo.
